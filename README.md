# FieldNotes-HR

## Repository contents

- **`learning-library/`** - a researched, roadmap-ordered learning library for breaking into HR through the Recruiter / Talent Acquisition path. Includes PDF, DOCX, Markdown, static HTML, an interactive tracker, sources and a verification log. Start with `learning-library/README.md`.
- **`.agents/skills/resource-learning-library/`** - the agent skill that produced the library, vendored here so it persists across sessions. Includes `SKILL.md`, renderer/validator scripts, requirements and offline tests. See `.agents/skills/README.md` for provenance and setup.
