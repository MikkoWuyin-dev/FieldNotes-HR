# FieldNotes-HR

## Repository contents

- **`learning-library/`** - a researched, roadmap-ordered learning library for breaking into HR through the Recruiter / Talent Acquisition path. Includes PDF, DOCX, Markdown, static HTML, an interactive tracker styled with the Fieldnotes design system, sources and a verification log. Start with `learning-library/README.md`; the design tokens and port notes are in `learning-library/DESIGN-SYSTEM.md`.
- **`.agents/skills/resource-learning-library/`** - the agent skill that produced the library, vendored here so it persists across sessions. Includes `SKILL.md`, renderer/validator scripts, requirements and offline tests. See `.agents/skills/README.md` for provenance and setup.
- **`.mcp.json`** - project-scoped registration of the `skill-issue` MCP skill collection. For each task, search it for relevant skills and use them; see `.agents/skills/README.md`.
